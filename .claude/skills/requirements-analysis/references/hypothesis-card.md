# 研究假设卡

用于 5E 学习智能体、学生数字孪生等无法直接写成确定需求的模块。假设卡不承诺功能，只承诺验证。

## 模板

| 字段 | 内容 |
|---|---|
| ID | `HYP-<模块>-<序号>` |
| 假设 | 我们相信〈对象〉在〈条件〉下会产生〈可观察变化〉 |
| 来源 | `S-xxx` / `D-xxx` / `R-xxx` |
| 验证指标 | 可测量的指标与口径 |
| 验证方式 | 原型 / 离线评估 / 小范围试用 / 对照实验 |
| 失败判据 | 什么结果说明假设不成立 |
| 决策 | 继续 / 调整 / 放弃；记录日期与决策人 |
| 关联需求 | `REQ-xxx` |

## 规则

- 指标必须有口径和来源；不得凭空设定阈值。
- 没有验证方式的假设不进入开发。
- 失败判据必须在开始前写定，不能事后补。
- 验证结果写回卡片，并同步到 `05-traceability.md`。
