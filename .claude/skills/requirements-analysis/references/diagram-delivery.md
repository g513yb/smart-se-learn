# 图的输出与交付

本文件规定建模源、导出图、目录表和 PPT 交付的通用规则；项目专用的模板、文件名和目录表内容写在项目文件里。

## 1. 源与图分开

- 源文件放在 `docs/requirements/models/src/`：Mermaid 为 `<模块>-<主题>.mmd`，表格为 `<模块>-<主题>.md`。
- 导出图放在 `docs/requirements/models/img/`，与源同名。
- 一图一源一图。同一张图只保留一种图像格式，不并存 SVG 和 PNG。
- `docs/requirements/models/README.md` 是目录表：图题、类型、回答的问题、源、图、主要来源、状态。新增、改名、删除或换图后同步更新。
- 源是唯一真相。导出图可以重新生成；不把截图或手改位图当作源。

## 2. 格式选择

- Mermaid 图默认导出 **SVG**：矢量、可缩放、PowerPoint 2016 及以上可直接插入，体积通常小于 PNG。
- 表格（决策表、数据清单）用 **Markdown 源 + PNG**：表格没有 Mermaid 源，PNG 可直接放进 PPT。
- 同一张图不生成两种格式。若交付环境只接受一种格式，全部用 PNG；SVG 只用于需要缩放、编辑或控制体积的场合。
- 不从截图或位图反推模型；源失真的图不能作为交付依据。

## 3. 导出

- Mermaid 用 mmdc 导出；固定主题、字体和白底，同一批图保持一致。
- 需要替换导出标签（如 Mermaid 的 alt/opt 改为中文）时，把导出步骤写在源文件头，保证可重复。
- 表格用 Markdown 表；需要图片时渲染为 PNG。图内不要重复幻灯片标题、来源和问题，避免与页面标题重复；必要说明放在表下小字。
- 导出后检查：文字不重叠、换行不破词、节点和箭头不被截断；大图按语义边界拆页。
- 字体依赖系统字体时，交付前在目标机器上检查；无法保证字体时改用 PNG。

## 4. 文件头与内容

- 图题、问题、来源、用途或待定项写在源文件头；文件名与图题一致，使用小写 kebab-case。
- 每个图元素必须有 `S/D/REQ` 来源；未回答的 `Q`、`P`、推断不作来源；设计内容进 `DSN-`。
- 没有来源的局部口径标“待定”，不编造；不画没有真实数据的雷达图、图表或概率数字。
- 图只回答一个问题；图型选择和最小化规则见 `modeling-guide.md`。

## 5. 在 PPT 中使用

- 使用项目指定的 PPT 模板；图源与 PPT 产物分开保存，PPT 目录按项目约定忽略。
- 放图前计算可用区域；保持纵横比，不拉伸。宽图顶部对齐，普通比例图居中。
- 拆页判据：整图放入后最短边文字低于约 8～10pt，或长宽比超过约 4:1 / 低于 1:3 时，按语义边界拆页。
- 拆页后标题标 `(1/n)`；不切断完整节点、判断框或消息；裁切会切到内容时，重绘子图或加“接上页/接下一页”，不硬裁。
- 拆页只是同一张图的视图，不新增需求元素。
- 幻灯片标题承担标题；图内不要再放大标题、来源、问题，避免重复。
- 表格类图片去掉标题和来源，只保留表格和必要注释。

## 6. 检查表

- [ ] 源在 `src/`，图在 `img/`，同名，一图一格式
- [ ] 目录表已更新
- [ ] 图头有问题、来源、用途或待定项
- [ ] 每个元素有 `S/D/REQ` 来源，没有未回答的 Q/P/I
- [ ] 没有设计内容、假数据或未确认的阈值
- [ ] 导出图文字不重叠、不被截断
- [ ] PPT 中图未拉伸，拆页未切断节点
- [ ] PPT 标题与图内标题不重复
