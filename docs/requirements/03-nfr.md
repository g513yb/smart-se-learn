# 非功能需求

按 `references/nfr-checklist.md` 逐项确认后填写；没有来源或决策的指标先写入 `07-dialogue.md` 的 Q 表。

| 类别 | 指标 | 场景与边界 | 来源 | 状态 | 确认人 | 确认日期 |
|---|---|---|---|---|---|---|

## 写入与确认

- 只写有 `S/D/R` 来源的指标；`P` 只能生成 Q，不能作为指标依据。
- 指标必须有场景与边界；没有来源或边界写 Q。
- 写入时状态为“待确认”；另一人评审，用户确认后写确认人/日期，状态改“已确认”。
- 安全、隐私、性能目标必须第二人评审；涉及合规或基线时两人一致。
- 变更已确认的 NFR 走 `06-changes.md` 的 CR；涉及基线或合规时两人一致。
- 状态：待确认 / 已确认 / 已废弃。
