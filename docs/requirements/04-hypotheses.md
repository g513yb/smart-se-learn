# 研究假设

用于 5E 学习智能体、学生数字孪生等模块。模板见 `.claude/skills/requirements-analysis/references/hypothesis-card.md`。

| ID | 假设 | 来源 | 验证指标 | 验证方式 | 失败判据 | 决策 | 状态 | 确认人 | 确认日期 |
|---|---|---|---|---|---|---|---|---|---|

## 写入与确认

- 只写有 `S/D/R` 来源的假设；`P` 只帮助设计，不能作为项目假设的依据。
- 假设、验证指标（含口径）、验证方式、失败判据缺一不写卡；缺的写 Q。
- 验证指标和失败判据必须在开始验证前写定，不能事后补。
- 另一人评审验证设计；对话成员确认后写确认人/日期。
- 状态：提议 / 验证中 / 成立 / 不成立 / 废弃。
- 验证结果写回卡片，并更新决策（记 `D`）。
