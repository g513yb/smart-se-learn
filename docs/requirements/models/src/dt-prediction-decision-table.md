# 预测可用性与输出判定

问题：选择未完成章节查看预测时，章节状态、服务可用性、数据充足性和知识点数据情况分别导致什么输出？

来源：REQ-DT-002、REQ-DT-006、Q-148、Q-149、Q-152、Q-153、Q-154、Q-157

判断顺序：章节状态 → 服务可用性 → 章节数据 → 知识点数据。这是暂定假设，不是已确认结论；Q-179 回答后按结论调整行序。

| 章节已完成 | 服务可用 | 有诊断且可用练习≥3 | 部分知识点数据不足 | 输出 |
|---|---|---|---|---|
| 是 | 任意 | 任意 | 任意 | 不提供预测 |
| 否 | 否 | 任意 | 任意 | 显示“预测暂不可用”；其他模块不受影响 |
| 否 | 是 | 否 | 任意 | 显示“数据不足，无法预测”；不给比例和得分区间 |
| 否 | 是 | 是 | 是 | 标记数据不足的知识点，不计入掌握比例；其余正常预测，比例按已判定知识点计算 |
| 否 | 是 | 是 | 否 | 正常预测：预计掌握比例、得分区间、可信度；可展开逐知识点；显示时间范围、依据的诊断章节、练习次数和“预测是估计而非事实”的说明 |

注：

- 知识点级数据不足的判定口径未写明，是否沿用掌握程度的“累计作答少于 3 题”待定。
- 可信度分高、中、低三档，阈值未写明。
