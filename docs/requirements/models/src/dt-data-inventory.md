# 数字孪生采集数据清单

问题：数字孪生每天同步哪些数据，每类已确认包含什么，哪些字段或口径待定？

来源：REQ-DT-001、Q-147、Q-182、Q-101、Q-102、REQ-LOG-001、REQ-LOG-002、REQ-LOG-003、REQ-LOG-004、REQ-LOG-005、REQ-DIAG-004、REQ-DIAG-005、REQ-DIAG-007、REQ-PROF-001、REQ-PROF-002、REQ-RECO-002、REQ-RECO-003、REQ-AGENT-009

说明：数字孪生同步五类来源的最新状态，不自行采集原始事件；具体字段级模型属于设计，清单确认后再进 设计说明。

| 来源 | 已确认的采集内容 | 同步用途 | 待定 / 缺口 |
|---|---|---|---|
| 学习记录 | 学习活动与内容访问、练习作答与成绩、计划接受与执行、自评问卷；事件字段含学生、类型、时间、课程、章节、节点、动作、时长、作答与得分等 | 预测依据（时间范围、练习次数）；趋势中的成绩和进度信号 | 智能体交互事件待 5E 模块接入；同步字段和粒度未写（设计项） |
| 学习诊断 | 章节诊断（按知识点的掌握程度和判断依据）、课程掌握总览 | 预测依据（依据的诊断章节、知识点）；趋势中的掌握结构 | 同步字段和粒度未写 |
| 学生画像 | 四维指标及指标值或标签、证据；每天更新 | 数字孪生预测输入 | 画像各指标的数据来源仍待定（Q-184）；数字孪生具体使用哪些维度或指标未写（Q-185） |
| 推荐计划 | 计划项（对应知识点、主学习节点、选择依据、执行状态）、复习练习、计划状态 | 模拟对比中的“完成推荐计划”情形 | 同步字段和粒度未写 |
| 个人计划 | 按课程组织、有序计划项；学生可删改和调整顺序；与推荐计划平行 | 模拟对比中可选的个人计划情形 | 个人计划的数据字段和状态未单独定义（设计项） |

注：

- “同步用途”只写已能从需求直接对应的用途；其余映射待定（设计项）。
- 学生画像采集已确认；画像仍不作为诊断、推荐的输入。
