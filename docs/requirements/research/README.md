# 对标调研

每个平台一份 brief，命名 `<平台>.md`；模块综合 brief 命名 `<模块>.md`；汇总矩阵 `comparison-matrix.md`。

预综合/工作稿命名 `<模块>-pre-synthesis.md`，不计入正式 brief；正式 brief 在 1.0 边界确认后创建。

## 现有资料状态

本目录现有 brief、预综合和汇总矩阵均为预分析资料：未经 1.0 模块边界确认，不计入正式 1a brief，不得作为需求来源或 1b 覆盖依据。资料中的 Q/P/REQ 引用可能指向已删除的对话记录，只作线索。正式 brief 在 1.0 通过后按 `research-guide.md` 重写。

Brief 固定六段：检索问题、来源清单、需求观察、设计线索、与本项目的差异、生成的 Q。

规则见 `.claude/skills/requirements-analysis/references/research-guide.md`。`P` 可以生成 Q，也可以支撑 AI 草案；草案需人确认，设计细节进 `docs/design-notes.md`。

快速调研不写正式 brief，输出 P 观察 + Q + 可选 AI 草案；草案标“AI 提议”，人确认后写入。
