# 来源文件

- 文件索引：`INDEX.md`
- 命名规则：`P-<三位序号>_<平台或主题>_<内容>_<年份或章节>.pdf`
- 本地归档目录：`_archive/`，存放被替代的目录页与首页，不参与分析（不进入公开仓库）
- 使用规则：只用“已批准”和“部分验证”；部分验证必须标注；`P-` 只生成 `Q`
- PDF 不进入公开仓库：本地保留副本；公开仓库只保留 `INDEX.md`、本说明和调研笔记；引用来源用 `P-ID`
- `_archive/` 和 `screenshots/` 也是本地目录，不进入公开仓库；公开仓库只保留 `INDEX.md`、本说明和调研笔记
