## 3. 需求观察（用户可见行为）

### Moodle（P-001、P-002）

- 学生：查看每个活动的完成状态，可手动标记完成；查看课程完成状态块；获得徽章。（P-001，全文）
- 教师：为每个活动设置完成条件；查看活动完成矩阵（学生 × 活动），可覆盖完成状态；查看课程完成报告、参与报告、活动报告、日志；查看风险学生分析洞察。（P-001，全文；P-002，全文）
- 管理员：在站点、课程、活动三级启用完成跟踪；配置分析插件。（P-001，全文）

### Open edX（P-003）

- 教师：访问课程范围的分析仪表板与讲师报告；查看学习者参与、进度，识别需要帮助的学习者。（P-003，摘要）
- 分析师 / 运营 / 开发者：更广泛的数据访问与仪表板；角色权限按课程范围配置。（P-003，摘要；这些角色不在本项目当前三角色内，见差异表）
- 学习者：检索摘要未显示独立的学习记录查看入口（未发现，不是确定没有）。（P-003，摘要）
- 管理员：配置课程范围权限。（P-003，摘要）

### Canvas（P-004）

- 教师：查看课程与学生分析、课程成绩；每周在线活动（页面浏览与参与，按周一到周日）；学生标签页；缺交与迟交作业；沟通记录；学生上下文卡片；模块进度；掌握度成绩册；视频参与洞察；风险学生提醒；CSV 导出；向学生发消息。（P-004，视频 / 文字稿）
- 学生：可查看自己的成绩、活动与沟通数据，需具备相应权限；模块进度可见。（P-004，视频 / 文字稿）
- 管理员：查看标准报告、数据导出。（P-004，视频 / 文字稿）
- 时效：官方视频称约 24 小时刷新。（P-004，视频 / 文字稿）

### xAPI（P-006）

- 分析师 / 审计人员：可按学习者、行为、活动、时间范围查询学习记录；记录可带附件。（P-006，摘要）
- 审计人员：能追溯记录的作废。（P-006，摘要）

### 超星学习通（P-012）

- 教师：能查看 9.2 课堂报告；9.3 学情统计，包括章节学习次数、章节任务点、课程签到、课程积分、课程作业、章节测验、课程考试、课程讨论、教学预警；9.4 成绩统计并导出。（P-012，页面级 / 视频）
- 证据强度为页面级 / 视频页面，具体统计口径需复核；不是官方完整文档。（P-012）

### 雨课堂（P-013）

- 教师：能查看成绩分析，包括最高分、最低分、平均分、标准差、难度、区分度、信度、得分率；题型结构统计；题目详情；知识点掌握分析。（P-013，成绩分析全文）
- 教师：能进入教学数据分类，包括课堂报告、学习分析 / 教学日志导出、学生画像预警等文章入口；具体文章未全部获取。（P-013，分类索引页面级）

### PrairieLearn（P-024）

- 本轮只取得评测能力摘要，未取得学习记录相关的用户可见行为；具体能力见设计线索 DSN-027，边界见 Q-042。（P-024，摘要）
