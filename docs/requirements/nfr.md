# 非功能需求

| ID | 类别 | 指标 | 场景与边界 |
|---|---|---|---|
| NFR-001 | 性能 | 章节内容页打开时间 ≤ 3 秒 | 学生和教师在普通网络下打开单个章节内容页；单门课最多 200 名学生、峰值同时在线 100 人 |
| NFR-002 | 性能 | 客观题提交后 ≤ 2 秒出分 | 学生提交一次练习的客观题；单门课最多 200 名学生、峰值同时在线 100 人 |
| NFR-003 | 性能 | 主观题 AI 批改 ≤ 1 分钟返回 | 学生提交一次主观题；单门课最多 200 名学生、峰值同时在线 100 人 |
| NFR-004 | 性能 | 完成后进度立即更新 | 学生完成章节内容后；单门课最多 200 名学生、峰值同时在线 100 人 |
| NFR-005 | 可用性 | 已提交的练习作答不因服务中断丢失 | 学生提交练习后发生服务中断 |
| NFR-006 | 可用性 | 计划维护安排在夜间 | 不影响学生正常学习时段 |
| NFR-007 | 安全 | 必须登录才能访问课程内容；按角色、班级和课程范围控制可见内容；账号密码不以明文保存 | 所有学生、教师、管理员访问 |
| NFR-008 | 隐私 | 学习数据仅学生本人和其本班教师可见；只用于平台内学习、诊断和推荐，不向外部提供 | 学习进度、练习作答、错题、成绩 |
| NFR-009 | 可解释性 | 每题对错和得分可见；AI 批改的主观题给出评分理由；进度按章节完成状态展示 | 学生查看练习结果和进度 |
| NFR-010 | 性能 | 章节诊断生成 ≤ 1 分钟 | 章节最后一个练习提交后；单门课最多 200 名学生、峰值同时在线 100 人 |
| NFR-011 | 性能 | 课程汇总更新 ≤ 1 分钟 | 章节诊断更新后；单门课最多 200 名学生、峰值同时在线 100 人 |
| NFR-012 | 可用性 | 诊断服务不可用时，学习和练习不受影响，已有诊断可查看 | 诊断服务中断时 |
| NFR-013 | 性能 | 通知生成 ≤ 10 秒 | 触发通知的业务结果生成后；教师修改计划后 |
| NFR-014 | 可用性 | 通知服务不可用时业务不受影响，已有通知可查看，未成功通知按 5 分钟重试 | 通知服务中断时 |
| NFR-015 | 性能 | 画像页打开 ≤ 3 秒；每日更新在次日 6 点前完成 | 学生和本班教师查看画像 |
| NFR-016 | 可用性 | 画像服务不可用时学习、诊断和推荐不受影响，已有画像可查看，次日更新重试 | 画像服务中断时 |
| NFR-017 | 可解释性 | 面向学生和教师的诊断、画像和推荐解释由 AI 润色为自然语言，并附指标证据 | 诊断、画像和推荐结果的展示 |
| NFR-018 | 性能 | 关注列表打开 ≤ 3 秒；教师提醒送达 ≤ 10 秒；干预记录生成 ≤ 10 秒 | 教师干预；单门课最多 200 名学生、峰值同时在线 100 人 |
| NFR-019 | 可用性 | 教师干预服务不可用时学生学习和诊断不受影响，提醒按通知规则重试，记录稍后重试 | 教师干预服务中断时 |
| NFR-020 | 性能 | 智能体首段回复 ≤ 3 秒开始显示，完整回答 ≤ 30 秒 | 学生向智能体提问；五步引导每一步同样适用 |
| NFR-021 | 可用性 | 智能体不可用时学习、练习、诊断、推荐和画像不受影响，已有对话可查看 | 智能体服务中断时 |
| NFR-022 | 性能 | 章节预测 ≤ 5 秒；模拟对比 ≤ 10 秒；打开已有预测页 ≤ 3 秒 | 学生和本班教师使用数字孪生 |
| NFR-023 | 可用性 | 数字孪生不可用时学习、练习、诊断、推荐、画像和教师干预不受影响 | 数字孪生服务中断时 |
| NFR-024 | 性能 | 账号列表打开 ≤ 3 秒；创建、修改、停用和重置密码等操作 ≤ 2 秒 | 管理员操作 |
| NFR-025 | 可用性 | 账号服务不可用时已登录用户可继续使用，新登录和账号操作暂停并提示 | 账号服务中断时 |
| NFR-026 | 性能 | 推荐触发条件满足后 ≤ 1 分钟生成计划并发送通知；教师修改后立即生效 | 推荐触发条件满足后；教师修改计划后 |
| NFR-027 | 可用性 | 推荐服务不可用时学习、练习和诊断不受影响，已有计划可查看；服务恢复后按定时重试规则重新生成 | 推荐服务中断时 |
| NFR-028 | 性能 | 单条学习事件写入 ≤ 1 秒；按学生和课程读取事件供诊断或画像使用的查询 ≤ 3 秒 | 单门课最多 200 名学生、峰值同时在线 100 人 |
| NFR-029 | 可用性 | 学习记录服务不可用时学习、练习和已有诊断画像不受影响；事件按 5 分钟重试规则补录 | 学习记录服务中断时 |
