# 术语表

| 术语 | 定义 |
|---|---|
| 课程内容学习（COURSE） | 本期模块；老师上传和组织课程内容，学生观看视频、阅读讲义、完成练习并获得成绩；不含课程制作、作业提交、在线考试、讨论区。 |
| 课程 | 教师开设、学生自行加入的学习单位。 |
| 章节 | 课程内容的组织单位，包含视频、讲义和练习。 |
| 节点 | 章节内的学习单元，包括视频、讲义和练习。 |
| 完成状态 | 视频播放到结尾、讲义打开、练习提交一次，即该项完成；章节内所有练习都提交过，才算该章节完成 |
| 学习进度 | 已完成节点数 ÷ 总节点数。 |
| 练习 | 章节内的题目集合；一个章节可以有多个练习，一个练习可以混合任意题型，按老师设定的顺序排列；提交一次即完成。 |
| 客观题 | 单选、多选、判断、填空，系统自动判分。 |
| 主观题 | 编程题、简答题、设计题，由 AI 批改并给出评分理由。 |
| 编程题 | 学生编写代码作答的主观题，由 AI 批改并给出评分理由。 |
| 简答题 | 学生用文字解释概念或原理作答的主观题，由 AI 批改并给出评分理由。 |
| 设计题 | 学生提交设计方案作答的主观题，由 AI 批改并给出评分理由。 |
| 错题 | 学生作答错误并被标记的题目。 |
| 通知（NOTIF） | 本期模块；只做站内通知，不做短信、邮件和系统推送。 |
| 学习诊断（DIAG） | 本期模块；基于练习成绩和错题，按章节和 AI 识别的知识点自动生成章节级诊断，课程级为汇总视图；学生和教师查看。 |
| 知识点 | 课程内容中可被题目检验的最小概念或技能，例如 for 循环、异常处理、单元测试；包含唯一名称、一句话定义、来源节点和关联节点，以及可关联的章节和题目。课程维护唯一清单，每个知识点记录出现的章节，可跨章节共用；由 AI 按章节从视频、讲义提取；相同知识点复用并追加来源，类似知识点提出合并建议，新知识点由 AI 直接加入清单、教师可修改；题目只在本章节知识点范围内匹配，匹配不上时标为未匹配、由教师处理，每题关联 1～3 个知识点。 |
| 掌握程度 | 按知识点分为掌握（得分率 ≥ 80%）、部分掌握（50%～80%）、未掌握（< 50%）；累计作答不足 3 题显示“数据不足”；判断依据包含作答题目数、得分合计与满分合计、错题清单和 AI 说明。 |
| 计划项 | 推荐计划中的一项，对应章节内的一个视频或讲义节点，包含选择依据和未执行、已执行两种状态；复习练习不属于计划项，按章节放在推荐计划下。 |
| 课程掌握总览 | 课程页上按知识点合并该课程各章节诊断的视图；某章节没有练习、无法生成诊断时，该章节不参与合并。 |
| 推荐计划 | 学习推荐给出的有序计划项列表，每项是章节内的视频或讲义节点并附选择依据，计划下按章节列出复习练习；学生可以接受，接受后可看到下一个待办节点提示；不接受时按忽略处理，不显示待办提示，日常学习不受影响。接受后计划内节点一律记为未执行，重新学习一次后标记已执行；不影响日常完成状态。完成全部复习练习并用其结果替换原练习结果、重新诊断后，课程掌握总览中不存在未掌握知识点即计划完成；未接受的计划在课程掌握总览中不存在未掌握知识点时可以删除。 |
| 复习练习 | 原练习的一个视图，按章节抽取未掌握知识点的错题和部分已答对题目；学生完整完成整个复习练习后，结果才写回原练习，作为一次新的提交与其他旧结果一起参与诊断；不计入章节完成状态。 |
| 学习推荐（RECO） | 本期模块；在课程内依据学习诊断和课程进度，为学生推荐章节内的节点；章节和节点顺序即默认学习计划，不单独生成，教师查看并反馈（标注不采用、给修改建议），不能直接修改或添加计划项；本期不以学生画像、学生数字孪生和 5E 学习阶段为依据。 |
| 学习记录（LOG） | 本期模块；采集并保存学习事件（时间、对象、事件类型、结果），向诊断、画像、推荐和教师干预提供数据，不产生诊断、画像或推荐结论。 |
| 班级 | 教师负责的一组学生；学生在创建账号时由管理员分配到一个班级，一个学生只属于一个班级。 |
| 学生画像（PROF） | 本期模块；按学生整体形成长期学习特征，学生查看全部，本班教师查看本班学生的画像。 |
| 教师干预（INTV） | 本期模块；教师查看本班学生学习状况，标记关注，向一个或多个学生发送站内提醒，对 AI 推荐计划项标注不采用并给修改建议，干预记录由系统在 AI 辅助下自动生成。 |
| 5E 学习智能体（AGENT） | 本期模块；学生可在任意页面向智能体提问，智能体基于课程节点回答并按 5E 环节引导系统学习。 |
| 个人学习计划 | 学生在与智能体对话中制定的学习计划，与推荐计划平行、互不影响，不参与诊断和计划完成判断。 |
| 学习趋势 | 未来 2 周内三项指标的变化方向：掌握结构（未掌握知识点数量增减、已掌握知识点占比升降）、成绩水平（练习平均得分升降）、学习进度（按当前节奏预计推进的章节或节点数）。三项分别判断，两项及以上改善且无恶化记为改善，两项及以上恶化且无改善记为恶化，其余记为稳定；可用指标少于两项时为数据不足。 |
| 学生数字孪生（DT） | 本期模块；基于学习数据构建学生模型，预测未来学习效果，学生和本班教师查看。 |
| 账号管理（ACCT） | 本期模块；管理员开通账号、分配角色和班级、设置账号密码、停用账号。 |
